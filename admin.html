Editor de fotos del catálogo

Carpeta no conectada — puedes editar y descargar las fotos igual, solo tendrás que arrastrarlas tú mismo a la carpeta.

Cómo funciona: elige una foto de tu computador, ajústala dentro del recuadro (arrastra para mover, usa el control para acercar/alejar) y guarda. Si conectaste la carpeta assets/img/productos, el archivo se reemplaza automáticamente con el nombre correcto — no necesitas tocar código ni el catálogo. Recárgalo (F5) para ver el cambio.

Recomendado: sube fotos de al menos 1200×1200 px para que se vean nítidas. El tamaño final que se guarda es 1200×1200 px, formato JPG.
